# YWCAIndia/.github

This repository holds the public profile shown on the Overview tab of the [YWCA of India organisation](https://github.com/YWCAIndia) on GitHub.

GitHub shows `profile/README.md` from a public repository named `.github` at the top of an organisation's page. Nothing else in this repository is displayed there.

## Editing the profile

- **Text:** edit `profile/README.md`. The wording is taken from [ywcaindia.org](https://ywcaindia.org/), so change it there first and copy it here.
- **Graphics:** the images are in `profile/assets/` as SVG files, which are plain text.
  - `banner.svg` is the heading image. The logo inside it is the official YWCA of India Logo from the [Identity Guide](https://i.ywca.in). Don't recolour or redraw it.
  - `stats.svg` shows the four headline figures. To change one, open the file in a text editor and edit the number inside its `<text>` tag. Update the image's `alt` text in `profile/README.md` to match.
  - `we-*.svg` are the three approach icons and `sdg-*.svg` the Sustainable Development Goal chips.
- **Figures:** the number of associations and states comes from the website's association list, and the other counts from its home page. When they change on the website, change them here too: in `stats.svg`, and in the text and tables of `profile/README.md`.

Images are linked by their full `raw.githubusercontent.com` address, so they only appear once this repository is public and the files are on the `main` branch.

Changes pushed to `main` show on the organisation page straight away.
